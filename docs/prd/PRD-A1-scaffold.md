## 1. 背景与目标

- **背景**：ftre 生态需要独立的文档站展示架构文档和设计计划。
- **目标**：React + Vite 文档站，Markdown 源文件自动渲染侧边栏。
- **非目标**：不依赖后端 API，独立部署。

## 2. 需求范围

### 2.1 功能需求

- [x] FR1：React + Vite 初始化文档站
- [x] FR2：Markdown 源文件放在 src/content/
- [x] FR3：侧边栏根据 content 目录结构自动渲染
- [x] FR4：Markdown 正确渲染（标题/列表/代码块/表格）

### 2.2 非功能需求

- 构建速度快（Vite）
- 响应式布局
